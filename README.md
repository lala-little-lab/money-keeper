# Money Keeper 本番版1.3（2026-11-06）

## 今回の変更
定期支払いの「指定日に自動記録する」を追加。初回日から到来した分を、アプリ起動時・画面復帰時・表示中の1分ごとの確認で支出記録として作成します。閉じている間にバックグラウンド実行はしません。

記録から通常の履歴・支出集計・カード請求へ反映。カード払いは購入時に銀行残高を減らしません。現金・口座等は支払元の残高を減らします。未来の定期払いをカード請求へ別途足す旧処理を止め、二重計上を防ぎます。将来分は指定日到来後に請求へ反映します。

## 登録方法
引落 → 定期支払い → ＋追加。「指定日に自動記録する」をON。
名前・金額・周期・開始日・カテゴリ・支払方法を設定します。「初回の記録日」は未入力なら開始日。指定する場合は開始日以降です。支払日・曜日は初回日に合わせるか空欄にします。
NISAを支出扱いにする場合の例：NISA積立、10,000円、毎月、開始日2026-11-16、支払方法楽天カード、カテゴリその他。カード会社の実際の請求月とも照合してください。
初回を過去にすると到来済みの分も作成されます。手入力済み・開始前未払いとして計上済みの分より後を指定してください。手入力の重複を自動判定する機能はありません。

## 合算請求とメモのみ
ドコモなどの請求総額を別に記録する場合、含まれるサブスクは自動記録をOFFにしてメモとして管理します。請求総額と個別サブスクの両方を自動で計上しないでください。
支出集計対象外・不定期はメモのみ。楽天Payは固定した実際の支払元を選択します。ポイント・クーポン・変動金額や請求月の個別調整は作成後の記録で編集します。

## 周期・期間限定・変更
毎月／毎週／2週間／2・3・6ヶ月／毎年／指定日・週・月数を処理。月末は当月末へ丸め、翌月は元の日に戻ります。
総回数は初回からの回数。終了日当日まで。回数と終了日の両方がある場合は早く到達したほうで終了。
停止は自動処理を保留。再開時は停止中の到来分も記録することを確認します。
金額やカテゴリ等の変更は未作成分に適用。作成済み記録は変更しません。作成後の周期・初回日変更は停止して別設定を作成してください。
生成済み回数を暗号化保存。再読込・バックアップ復元でも再作成しません。生成記録を削除しても再生成しません。設定を削除しても過去の記録は残ります。
請求額確定済み・引落済みの請求への追加は停止し、画面に理由を表示します。
既存の定期支払いは自動でONにしません。「メモのみ」と表示し、編集で初回日等を確認してONにします。
