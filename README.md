# Money Keeper 本番版1.5（2026-11-11）


- 設定 → ボタン配置 → チャージ元に「一覧から外す」を追加。口座・カード・過去の記録は削除しません。再追加できます。「いつものチャージ元」に使用中なら先に別の元へ変更するよう案内します。
- 支払方法編集の文言を「支払方法の選択肢に表示する」「チェックを外しても、過去の記録・請求は残ります。」に変更。非表示の仕組みは従来どおりです。
- 引落済みのカード請求を口座準備・入金のやることから除外。入金と資金移動は同じ現在残高を使います。複数の引落日を口座単位で累積し、不足額を計算します。
- 「引落口座の準備」を実装。対象は今日から2か月後の同日まで（月末は末日に補正）。未処理の過去のカード請求も含めます。給与日基準にはしません。
- 口座ごとに予定明細、合計、現在残高、最初の不足日・不足額、期間分をまとめて用意する額を表示。十分なら「登録済み予定分は準備OK」。安全枠や予定収入は加算しません。
- 対象は登録済みカード請求と、自動記録ON・停止していない銀行口座の定期払い。記録済みの口座定期払いは現在残高に反映されているため再計上しません。回数・終了日を尊重します。メモのみの定期払い、現金・電子マネー払いは対象外。
- 将来の未記録カード定期払いは従来どおり請求予定に追加せず、画面に対象範囲を明記。カード定期払いは記録後にカード請求として数え、二重計上しません。将来の買い物も含みません。
- カード請求欄を「締め日：○日 ／ 確定日：○日」「引落日：翌月○日 ／ 引落口座：口座名」の2行に変更。確定日は設定済みの確認開始日、未設定なら「未設定」。自動確定はしません。口座名の短縮処理は追加しません。

## 変更しないもの
- 記録画面の日付の維持・リセット規則、時計表示、定期払いの実記録処理、カード請求確定操作。
- 暗号化方式・データスキーマ12・バックアップ形式。初期設定のやり直しや復元は不要です。
- 休日の実引落日への自動補正は今回の対象外です。
