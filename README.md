# 本番版1.6 更新内容（2026-11-11）

## 口座準備の表示
- 口座名の横に▼を表示。口座名を押すと内訳を展開し、▲で閉じます。初回は閉じています。画面の定期再描画でも同じ起動中の開閉状態を維持します。開閉は保存データには追加しません。
- 内訳だけを折りたたみます。対象の引落合計・現在残高・不足額・準備OK・先の不足見込みは常時表示します。
- 合計と残高を右側の共通幅の2列で表示。項目名は左揃え、金額は右揃え。桁数の違いで項目名の開始位置が動かない配置です。
- 不足の枠は薄いピンク、金額はローズ色の太字。日付・補足はグレー。「○/○の引落前までに ¥○○ 不足」を同じ行に配置し、狭い画面では自然に折り返します。別の警告画面の色は変更していません。

## 準備額とやることリスト
- 主な引落日27日・翌月4日・10日をまとめて準備するため、今日から次に迎える10日までの未払い分を計算します。1〜10日は当月10日まで、11日以降は翌月10日まで。27日以前など、その他の日付の支払いも除外しません。未処理の過去分も引き続き含みます。
- 例：11/11時点では12/10まで。12/10当日もその日まで。12/11からは1/10までです。画面に具体的な対象期間を表示します。
- やることリストは口座ごとに1件。次の10日までの合計から現在残高を引いた不足額を表示し、期限は最初に残高が不足する日です。同日の支払いは合算。十分なら入金項目を表示しません。
- 給与入金・資金移動を記録すると現在残高で再計算します。予定給与は先取りして加算しません。引落済みカード請求は除外、口座定期払いの記録済み分も二重計上しません。
- 今日から2か月先の予定は内訳に「その先の予定」として残し、常時表示の補足に「○/○までの不足見込み：¥○○（変動あり）」を表示します。先の不足だけでは入金のやることを出しません。
- 今回の西武信用金庫の例：12/10まで119,009円、12/27分を含む総額150,046円、残高178,802円なら入金項目は出ません。
- 3万円等への金額切り上げや安全枠は追加しません。実際の入金額は利用者が判断します。

## 維持する仕様
- 登録済みのカード請求と自動記録ON・停止していない銀行口座の定期払いが対象。将来の買い物・未記録のカード定期払い・予定収入は含みません。確定前の金額は変動します。
- 記録・編集・暗号化保存・バックアップ・データスキーマ12・定期自動記録・カード日付設定・チャージ元設定は変更しません。
- 休日の実引落日への自動補正は追加していません。

## 検証と確認事項
- 27日・4日・10日の累積合計、同日の合算、最初の不足日、期間全体との区別、給与・資金移動後の不足解消、引落済み除外、10日/11日・年越し境界、その他の日の支払い、旧設定銀行、口座定期払いの停止・回数制限・記録済み除外を確認。
- 折りたたみの開閉・aria属性・定期再描画時の状態維持・HTMLエスケープを確認。記録処理・保存処理のソースが1.5から変わっていないことと、既存の記録・請求・定期払い・保存再試行の回帰検証を確認。
- 実ブラウザの目視・タッチ操作はこの環境では未確認。更新後、スマホ上で項目名の揃い方、開閉、色と折り返しを確認してください。
